# Converged conventional LL reference

This directory stores the paper-scale Landau-level comparison for the same
physical tMBG parameters and flux used by the primary hybrid-Wannier example.

Parameters:

- LL-code flux `1/10`, equivalent to physical moiré-cell flux `1/20`;
- target central-spectrum band `82`;
- rank-one projector;
- `NLL=400`;
- magnetic momentum mesh `40 x 16`;
- `theta=1.04 deg`, `kappa=0.70`, `U=50 meV`, and hBN potential `-30 meV`.

Saved result:

- mean target energy `25.0470775835 meV`;
- Chern number `-1` in the LL orientation convention;
- integrated trace excess `eta=0.098808121157`;
- integrated metric trace `6.38199342834`;
- integrated absolute Berry curvature `6.28318530718`.

`quantum_geometry.npz` contains the local fields and metadata.
`trace_condition_summary.txt` is the human-readable summary.
`quantum_geometry.pdf` and `quantum_geometry.png` are generated by
`reference_methods/landau_level/plot_ll_quantum_geometry.py`.

This result is supplied as a conventional-method comparison reference.  It is
not an input to the independent hybrid-Wannier calculation.
